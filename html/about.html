About Us & Contact

Curious about who's behind this site or need to reach the department? You've come to the right place — everything starts here.

This website showcases the EFREI Computer Science Department — designed to help prospective students, current learners, and industry partners understand who we are and what makes our program worth exploring. It was built as part of our TI402 Web Development course, applying everything from semantic HTML to interactive JavaScript.

Built for Learning, Designed for You

The TI402 Web Development project

This multi-page responsive website was created by students to demonstrate practical application of web development skills. The project covers everything from planning and design in Figma to implementing clean HTML5, modern CSS3, and interactive JavaScript features — all while following accessibility best practices and W3C standards.
