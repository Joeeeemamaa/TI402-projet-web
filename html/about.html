About Us & Contact

Learn about the student team behind this project, and get in touch with the EFREI Computer Science Department.

This website was created as part of the TI402 Web Development project at EFREI Paris. The goal was to design and build a complete showcase website for the EFREI Computer Science Department, applying HTML5, CSS3, and JavaScript skills acquired during lectures and lab sessions.

About this project

TI402 – Web Development

The project required creating a multi-page responsive website following a provided graphic charter and site structure. The team was responsible for all design decisions, content writing, HTML structure, CSS styling, and JavaScript interactivity. The mockup was designed first using Figma before moving to implementation.
