# TI402 – EFREI Computer Science Department Website

Showcase website for the EFREI Computer Science Department, built as part of the **TI402 Web Development** project at EFREI Paris.

## Tech Stack

- **HTML5** — semantic markup, W3C valid
- **CSS3** — custom properties, flexbox, grid, responsive design
- **JavaScript** — vanilla JS, no frameworks or libraries

## Pages

| File | Description |
|------|-------------|
| `html/index.html` | Home page with hero carousel and site overview |
| `html/courses.html` | Courses & Training Programs |
| `html/background.html` | Skills & Academic Background |
| `html/opportunities.html` | Academic & Career Opportunities |
| `html/faculty.html` | Faculty, research areas & office hours |
| `html/about.html` | Project team & contact form |

## Features

- Responsive layout with mobile navigation
- Hero carousel with auto-play and swipe support
- Scroll reveal animations on cards and sections
- Tab switcher for skills categories
- Accordion for course details
- Office hours table with current day highlight
- Contact form with live validation
- Back-to-top button
- Animated stats counter on home page

## Graphic Charter

Follows the official EFREI Computer Science Department design guidelines:
- **Academic Blue** `#0A316C` — primary colour
- **Technological Cyan** `#81ECEC` — interactive accents
- **Electric Yellow** `#FDCB6E` — calls to action
- Fonts: **Montserrat** (headings) + **Open Sans** (body)
